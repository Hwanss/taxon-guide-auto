# TaxonGuru 한·영 스토리텔링·이미지 강화 자동 예약발행 v4.3

이번 버전은 실제 실행 로그에서 확인된 다음 문제를 수정합니다.

- 장문 HTML을 JSON 문자열 안에 넣어 생성하면서 발생한 `Invalid JSON: EOF` 오류
- 영어 글이 빈 본문으로 저장되던 문제
- 한국어 재작성 후에도 근거 없는 외형·인물 수식어가 남던 문제
- 대표 이미지가 오래된 흑백 자료 이미지로 지정되던 문제
- 영어 본문에 삽입 이미지가 하나도 없던 문제
- 재작성할 때 영문 슬러그가 달라져 새 임시글이 중복 생성될 수 있던 문제

## 교체할 파일

GitHub 저장소에서 다음 3개 파일을 같은 경로로 덮어씁니다.

```text
main.py
requirements.txt
.github/workflows/schedule.yml
```

WordPress의 `TaxonGuru Multilingual Bridge` 플러그인은 기존 1.0.0을 그대로 사용합니다.

## 핵심 변경 사항

### 1. 긴 본문을 JSON으로 생성하지 않음

기존에는 제목, 태그, SEO 정보, 수천 자짜리 HTML 본문을 한 번에 JSON으로 반환받았습니다. 긴 HTML 문자열이 중간에서 잘리면 전체 JSON이 무효가 되어 영어 본문이 비거나 `EOF while parsing a string` 오류가 발생했습니다.

새 구조는 다음과 같습니다.

```text
본문 HTML: 일반 장문 출력으로 생성
제목·슬러그·요약·태그: 별도의 작은 JSON으로 생성
품질검사: 작은 JSON으로 생성
```

장문 출력은 완성 여부, 분량, 인용 수, 이미지 자리표시자를 검사한 뒤 최대 3회 재시도합니다.

### 2. 근거 없는 표현 자동 제거

프롬프트와 검수 규칙에 다음 제한을 추가했습니다.

- 연구 패키지에 없는 몸 구조·색상·행동·역사·수치 생성 금지
- `제왕적`, `전설적인`, `세계적인` 등 근거 없는 인물 수식어 금지
- 색상과 외형은 연구자료에 있을 때만 사용
- 검수 실패 시 최대 2회 재작성
- 재작성 때 unsupported claim을 명시적으로 제거

### 3. 영어 글 빈 본문 방지

영문 글은 다음 조건을 생성 단계에서 통과해야 다음 단계로 넘어갑니다.

```text
영문 850단어 이상
인용표시 4개 이상
[[IMAGE_1]], [[IMAGE_2]] 각각 1개
한국어 문자 없음
빈 제목·요약·태그 금지
```

3회 생성에도 실패하면 빈 글을 저장하지 않고 영문 오류를 시트에 기록합니다. 한국어가 통과한 경우에는 한국어만 예약하고 상태를 `한국어예약/영문검수필요`로 표시합니다.

### 4. 이미지 구성 변경

기본 이미지 구성은 다음과 같습니다.

```text
대표 이미지 1개: GPT Image로 생성한 컬러 과학 에디토리얼 이미지
본문 이미지 1: 최신·사진형 Commons 우선, 없으면 AI 서식환경 이미지
본문 이미지 2: 최신·사진형 Commons 우선, 없으면 AI 형태·행동 이미지
```

- 대표 이미지는 1536×1024 가로형
- 흑백 도판·판화·스케치는 대표 이미지에서 제외
- AI 이미지는 실제 관찰 사진이 아닌 설명용 재현 이미지임을 캡션에 표시
- 같은 본문 이미지 2개가 한국어 글과 영어 글 모두에 삽입
- AI 생성이 실패하면 Commons 자료를 최종 대체 이미지로 사용

### 5. 기존 임시글을 ID로 갱신

현재 시트의 바다돼지 행에는 다음 게시물 ID가 기록되어 있습니다.

```text
한국어 WP_POST_ID: 283
영어 EN_POST_ID: 284
```

새 코드는 슬러그만 찾지 않고 시트의 게시물 ID를 우선 사용합니다. 따라서 `재작성` 후 실행하면 새 임시글을 추가하지 않고 기존 283번과 284번 글을 갱신합니다.

## GitHub Actions 이미지 설정

새 `schedule.yml`에는 다음 값이 이미 들어 있습니다.

```yaml
ALLOW_AI_FEATURED_IMAGE: 'true'
PREFER_AI_FEATURED_IMAGE: 'true'
GENERATE_AI_BODY_IMAGES: 'true'
ALLOW_HISTORICAL_BODY_IMAGES: 'false'
MIN_BODY_IMAGES: '2'
AI_IMAGE_QUALITY: 'medium'
```

따라서 GitHub Secret의 `OPENAI_API_KEY`가 유효해야 합니다. 이미지 API 사용량에 따라 비용이 발생합니다.

## 적용 및 재실행 순서

1. GitHub의 `main.py`, `requirements.txt`, `.github/workflows/schedule.yml`을 교체합니다.
2. Google Sheets `taxonguru` 탭에서 `Scotoplanes globosa` 행의 상태를 `검수필요`에서 `재작성`으로 변경합니다.
3. GitHub `Actions → TaxonGuru Bilingual Story Auto-Publish → Run workflow`를 실행합니다.
4. 정상 로그를 확인합니다.

```text
한국어 장문 생성
한국어 자동검수
영어 장문 생성
영어 자동검수
AI 대표 이미지 생성 완료
AI 또는 Commons 본문 이미지 2개 준비
한국어 예약
영어 예약
한·영 예약 완료
```

5. WordPress에서 기존 한국어 283번, 영어 284번 글이 갱신됐는지 확인합니다.

## 정상 결과

```text
Google Sheets 상태: 한영예약완료
한국어 글: 예약됨
영어 글: 예약됨
대표 이미지: 컬러 AI 설명용 이미지
한국어 본문 이미지: 2개
영어 본문 이미지: 2개
```

품질 기준을 통과하지 못하면 공개 예약하지 않고 초안으로 유지합니다. 자동화 코드를 개선해도 애드센스 승인이 보장되는 것은 아니므로 기존 게시물의 사실성, 출처, 이미지 권리, 사이트 소개 및 편집정책도 함께 관리해야 합니다.
