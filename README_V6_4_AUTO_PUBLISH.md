# TaxonGuru AdSense Recovery v6.4

목표: AdSense 재심사 전 품질을 유지하면서 `수동검수대기`를 사람이 전부 확인하지 않아도 되도록 엄격한 자동 최종검수 후 조건부 공개합니다.

## 원칙

- 모든 수동검수대기 글을 무조건 자동 공개하지 않습니다.
- KO/EN 점수, 출처, 본문 분량, 이미지, 언어 혼입, AI 템플릿 흔적, 한영 반복, Google/Vertex 중계링크, 정책 링크를 다시 검사합니다.
- 모든 조건을 통과한 한·영 글 쌍만 공개합니다.
- 공개 후 실제 URL을 다시 읽어 렌더링 검증합니다.
- 공개 후 검증 실패 시 이번 실행에서 공개한 글만 원래 상태로 롤백합니다.
- 기존 글이 기준 미달이고 재작성 가능하면 자동으로 `기존재작성대기`로 돌려 다시 개선합니다.
- 재작성 한도를 모두 사용했거나 자동 판단이 어려운 글만 `사람검수필요`로 남깁니다.

## 기본 자동공개 기준

- 한국어 품질점수: 98점 이상
- 영어 품질점수: 96점 이상
- 자료수: 4개 이상
- 한국어 본문: 한글 2,600자 이상
- 영어 본문: 950 words 이상
- 본문 이미지: 2개 이상
- 대표 이미지 필수
- Google/Vertex 중계 출처: 0
- AI 고정 템플릿/한영 반복/언어 혼입/가상 전문가 표현: 0
- 참고자료 섹션 및 AI 활용정책 링크 필수
- 직접 출처 404/410 링크: 0

## 안전장치

- 회당 최대 4건만 처리
- WordPress 오류 시 자동 공개하지 않음
- KO/EN 중 하나라도 실패하면 공개하지 않음
- 공개 후 HTTP/렌더링 재검증 실패 시 변경된 글만 원래 상태로 복귀
- Google/Vertex 중계링크 또는 구조적 품질 문제는 자동 공개 금지
- 신규 콘텐츠의 일반 자동발행은 AdSense 복구모드에서 계속 비활성화
